# Account Analysis Prep (PEREPA EDU)

Four skills for preparing account analysis for month-end, year-end close and statutory/internal audit, using Indian conventions (INR, Ind AS / AS, Schedule III, GST, TDS, April–March fiscal year).

- trial-balance-mapping: map a trial balance to Schedule III groupings and check it balances
- gl-account-scrutiny: scrutinise GL ledgers for unusual, duplicate or misclassified entries
- account-analysis-schedules: build audit-ready breakup schedules for each balance sheet account, tied to the TB
- ageing-confirmation-recon: debtor/creditor/advance ageing, MSME 43B(h) flags, and ledger vs party statement reconciliation

Typical order: trial-balance-mapping → gl-account-scrutiny → account-analysis-schedules → ageing-confirmation-recon.

Data comes from uploaded Excel/CSV exports (Tally, SAP, Zoho Books, etc.), or from Google Drive / Microsoft 365 when those connectors are enabled.
Working papers go out as Excel; client-facing summaries follow PEREPA EDU navy/gold branding as Word or PPTX.
