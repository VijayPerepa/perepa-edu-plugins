# Finance Analysis (PEREPA EDU)

Four skills for finance and accounting work using Indian conventions (INR, GST, TDS, April–March fiscal year).

- variance-ratio-analysis: budget vs actual, MoM/YoY trends, ratio analysis
- gst-tds-reconciliation: purchase register vs GSTR-2B, TDS rate/shortfall checks
- financial-statement-review: P&L, balance sheet, cash flow commentary
- finance-training-lab: turn a dataset into a lab/exercise with sample data and worked solutions

Data comes from uploaded Excel/CSV files, or from Google Drive / Microsoft 365 when those connectors are enabled.
Client-facing outputs follow PEREPA EDU navy/gold branding as Word or PPTX.
