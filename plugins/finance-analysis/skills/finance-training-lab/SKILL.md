# Finance Training Lab

1. Ask for the tool (Excel, Power BI, SQL, Power Apps) and level only if not stated.
2. If the user supplied data, anonymise names and GSTINs/PANs. If not, generate realistic Indian sample data (INR, GST 5/12/18/28%, TDS sections, April–March FY) with a few deliberate errors for learners to find.
3. Structure the lab: objective, dataset description, tasks (graded easy to hard), worked solution with formulas/DAX/SQL, expected outputs, check totals.
4. Save the dataset as Excel/CSV and the lab as a PEREPA EDU navy/gold Word document; add PPTX only if asked.
5. Verify every expected output by running the calculation in code.
